# Category image prompts

One image per category, all in the same style so the menu and the home page's category tiles read as one set.

**Where it goes:** Admin → Categories → pick the department tab → **Edit** on the category → **Image** → Upload → **Save**.
The image appears on the home page's "Shop by category" tiles (for categories switched to *Show on home page*) and, for a department with no products yet, in its menu panel.

**Tips**
- Keep the shared style text unchanged in every prompt, so the set looks consistent.
- If your tool supports it, ask for a **transparent background** version too: a cut-out garment sits best on the home page tiles.
- These are stand-ins until real photographs of your own pieces exist. Swap them for real product shots as soon as you have them.
- Save each file with the category's slug as its name (e.g. `men-shirts.png`) so they are easy to match up.

**Shared style (already included in every prompt below):**

> Ghost-mannequin (invisible mannequin) studio product photograph, front view, centred, the garment filling about 70% of the frame height. Seamless warm off-white background (#F3F1EC), soft diffused daylight from the upper left, a subtle natural shadow beneath, true-to-life fabric texture and stitching, crisp focus. Clean, minimal, premium high-street catalogue look (H&M / Zara / COS). No model, no props, no hangers, no text, no logo, no watermark. Portrait 4:5, 1600 x 2000 px.
